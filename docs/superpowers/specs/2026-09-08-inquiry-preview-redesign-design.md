# AI 探究式教学助手成果预览重设计

## 目标

将现有交互预览从“静态幻灯片拼接”升级为一份可演示、可导航、内容可信的产品成果展示，内容严格以《平台未来发展方向与测试规划.md》为准。

## 设计

- 采用 10 页宽屏展示结构：定位、核心差异、教师工作台、知识库授权、昆虫生命周期标杆场景、数据闭环、后台建设、质量与安全、并发测试、路线图。
- 视觉采用自然教育与科研工作台结合的风格：暖白纸张、深墨绿、湖蓝、琥珀色，减少装饰性大图，增加数据卡片、流程图、阶段标签和验收指标。
- 所有“当前能力”和“未来规划”明确区分，测试指标标注为建议验收目标，不把规划写成既成事实。
- 底部固定导航包含可见、可拖动的时间轴滑块；拖拽、点击刻度、键盘方向键和触摸滑动均可翻页。
- 保持单文件 HTML、无外部依赖、中文界面、可全屏展示和备注面板。

## 验证标准

1. 文件可被浏览器直接打开，页面无 JavaScript 语法错误。
2. 10 个页面均可通过底部滑块定位，滑块位置与页码同步。
3. 键盘翻页、全屏、备注面板和触摸切换继续可用。
4. 文案覆盖 Markdown 中的当前定位、昆虫生命周期场景、后台、学生数据、多模态、课程包、质量安全、并发测试和路线图重点。
